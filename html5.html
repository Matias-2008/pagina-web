HTML5

Lenguaje de marcado de hipertexto — curso de Programación Web I

¿Qué es HTML5?

HTML5 es el lenguaje de estructura y contenido de toda página web. Define los elementos (texto, imágenes, videos, enlaces) y la semántica del documento. Junto a CSS3 forman la base de todo lo que desarrollo como estudiante de Ingeniería de Sistemas.

Etiquetas semánticas

header, nav, main, section, article y footer dan significado a cada parte.

Multimedia nativa

<video> y <audio> integran contenido sin plugins externos.

Formularios

Controles nuevos como email, date, range y validación nativa.

Canvas y SVG

Gráficos y dibujos dinámicos directamente en el navegador.

Estructura básica

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>
    <header>
      <h1>Hola mundo</h1>
    </header>
    <main>
      <p>Bienvenido a mi sitio.</p>
    </main>
  </body>
</html>

Esta estructura es el punto de partida de todas mis prácticas: la etiqueta <h1> para títulos, <p> para párrafos y las etiquetas semánticas que organizan la página.
