Envío de Correos

Examen parcial de Desarrollo Web Full Stack — integración de EmailJS sin backend.

¿Cómo funciona?

Este formulario usa EmailJS desde el navegador, sin backend ni claves privadas. Se valida cada campo antes de enviar y se muestra una notificación según el resultado.

  • Validación de campos vacíos
  • Formato de correo válido
  • Mensaje de mínimo 10 caracteres
  • Estado de carga al enviar
