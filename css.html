01. ¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que da estilo y diseño a los documentos HTML. Como estudiante de esta asignatura, lo uso para controlar colores, tipografías, espacios y la disposición de cada elemento de la página.

Selectores

Apuntan a elementos del HTML para aplicarles estilos: .clase, #id, etiqueta.

Modelo de caja

Cada elemento es una caja con margin, border, padding y contenido.

Flexbox

Distribuye elementos en una línea o columna y alinea el contenido fácilmente.

Grid

Crea estructuras en filas y columnas, ideal para el layout de una página completa.

02. Ejemplo de sintaxis

/* Selector de clase */
.boton {
    background: linear-gradient(135deg, #8b5cf6, #06b6d4);
    color: #fff;
    padding: 12px 28px;
    border-radius: 50px;
    transition: transform 0.3s;
}

.boton:hover {
    transform: translateY(-3px);
}

Un h1 simple puede transformarse por completo con solo unas líneas de CSS. Este estilo sobrio y moderno que ves en el portafolio está construido 100% con estas técnicas.
